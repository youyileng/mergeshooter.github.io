## About Merge Shooter

Merge Shooter is a strategic tank defense game where players merge identical tanks to create powerful units and defend their base against endless waves of enemies.

### Key Features
- Strategic tank merging mechanics
- Intense tower defense gameplay
- Progressive upgrade system
- Endless wave survival mode
